<Steps>

1. **注册 / 登录**

   打开 [apex1.us/signin](https://apex1.us/signin)，输入邮箱收验证码即可，不需要密码。第一次登录会自动创建账号。

2. **充值**

   在控制台「充值与账单」里充值，最低 $0.50，支持银行卡、支付宝、微信支付。余额按分钟扣，不会从你的卡上自动扣款。

3. **开一台机器**

   控制台点「开新机器」，选三样东西：

   - **机器配置**：S（2 核 / 4 GB）或 M（4 核 / 8 GB）。
   - **预装工具**：选「预装 AI 编码工具」（Claude Code、Codex、Node、Docker 等），或「纯净系统」。
   - **Claude 账号**：「自己登录」不加价；或选 **Claude Pro**（+$40 / 30 天），我们替你登录。

   再贴上你的 **SSH 公钥**（没有的话先在本机 `ssh-keygen -t ed25519` 生成，`cat ~/.ssh/id_ed25519.pub` 查看）。约 15 秒开通完成，预装工具再要约 2 分钟。

4. **开放 SSH 端口并连接**

   在机器页「外部访问」里开放机器内的 **22** 端口，会分配一个外部端口（20000–29999 之间）。然后：

   ```bash
   ssh -p <外部端口> dev@<服务器 IP>
   ```

   机器页上有现成的命令可以直接复制。详见 [用 SSH 连接](/zh-cn/getting-started/connect/)。

5. **启动 Claude Code**

   ```bash
   cd ~/workspace
   claude
   ```

   第一次运行会提示登录：自己的账号按 [登录 Claude](/zh-cn/claude/sign-in/) 操作；买了 Pro 的，等我们登好后直接用。

</Steps>

<Aside type="note">
	新机器**默认一直开着**，按开机时长计费、每月最多收上限价。想闲着时省钱，可以在开通时或机器页里打开[自动待机](/zh-cn/machines/auto-standby/)。
</Aside>
