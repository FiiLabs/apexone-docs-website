## 安装 Node.js

推荐使用最新的 **LTS（长期支持）**版本。ApexOne 要求 **Node.js 22.x 或更高**。

<Tabs syncKey="os">
	<TabItem label="Windows">

	<Steps>

	1. 打开 [nodejs.org](https://nodejs.org)。
	2. 下载最新的 **LTS** 安装包。
	3. 运行下载好的 `.msi` 文件，按向导完成安装。
	4. 继续之前先重启终端。

	</Steps>

	</TabItem>
	<TabItem label="macOS">

	**推荐：NVM** —— [NVM](https://github.com/nvm-sh/nvm) 可以管理多个 Node.js 版本，并按项目切换。

	```sh
	# 安装 NVM
	curl -o- https://raw.githubusercontent.com/nvm-sh/nvm/v0.40.5/install.sh | bash

	# 重新加载 shell 配置
	source ~/.zshrc

	# 安装最新的 LTS 版本
	nvm install --lts

	# 设为默认版本
	nvm alias default 'lts/*'

	# 立即使用
	nvm use --lts
	```

	**备选：Homebrew**

	```sh
	brew install node
	```

	</TabItem>
	<TabItem label="Linux">

	**推荐：NVM**

	```sh
	# 安装 NVM
	curl -o- https://raw.githubusercontent.com/nvm-sh/nvm/v0.40.5/install.sh | bash

	# 重新加载 shell 配置
	source ~/.bashrc

	# 安装并使用最新的 LTS 版本
	nvm install --lts
	nvm alias default 'lts/*'
	nvm use --lts
	```

	**备选：包管理器**

	```sh
	# Ubuntu / Debian
	sudo apt update && sudo apt install -y nodejs npm

	# Fedora / RHEL / CentOS
	sudo dnf install -y nodejs
	```

	<Aside type="caution">
		发行版自带的包往往落后好几个大版本。如果 `node --version` 显示低于 22，
		请改用上面的 NVM，或者用 [NodeSource](https://github.com/nodesource/distributions) 装一个当前版本。
	</Aside>

	</TabItem>
</Tabs>

### 验证 Node.js

打开终端执行：

```sh
node --version
npm --version
```

输出示例：

```
v22.14.0
10.9.2
```

两条命令都能打印版本号，说明 Node.js 安装成功。

## 安装 Git

Git 是一个分布式版本控制系统，Claude Code 与大多数现代开发流程都会用到它。

<Tabs syncKey="os">
	<TabItem label="Windows">

	<Steps>

	1. 打开 [git-scm.com/download/win](https://git-scm.com/download/win)。
	2. 下载并运行最新的安装包。
	3. 安装过程中推荐选择：
	   - **Git from the command line and also from 3rd-party software**
	   - **Use Windows' default console window**
	4. 其余保持默认设置完成安装。

	</Steps>

	</TabItem>
	<TabItem label="macOS">

	**方式一 —— Homebrew**

	```sh
	brew install git
	```

	**方式二 —— Xcode 命令行工具**

	```sh
	xcode-select --install
	```

	**方式三 —— 官方安装包：**从 [git-scm.com/download/mac](https://git-scm.com/download/mac) 下载。

	</TabItem>
	<TabItem label="Linux">

	```sh
	# Ubuntu / Debian
	sudo apt update && sudo apt install -y git

	# Fedora / RHEL / CentOS
	sudo dnf install -y git
	```

	</TabItem>
</Tabs>

### 验证 Git

```sh
git --version
```

输出示例：

```
git version 2.43.0
```

能打印出版本号，说明 Git 安装成功。

### 配置 Git

安装完成后，配置你的 Git 身份：

```sh
git config --global user.name "Your Name"
git config --global user.email "you@example.com"
```

查看当前配置：

```sh
git config --list
```

<Aside type="note">
	你的 Git 用户名与邮箱会出现在提交历史里。请使用与你开发工作相对应的身份。
</Aside>

## 排障

<Aside type="caution" title="Node.js 安装失败（Windows）">
	如果安装包运行失败：以**管理员身份**运行、临时关闭杀毒软件，并确认磁盘空间充足。
</Aside>

**找不到 `npm` 命令**

- **Windows** —— 确认 Node.js 的安装目录已经加入系统 `PATH`。
- **macOS / Linux** —— 重启终端，或重新加载 shell 配置：

  ```sh
  source ~/.zshrc   # 或 ~/.bashrc
  ```

**Git 显示乱码**

如果 Git 把非英文文件名显示成乱码：

```sh
git config --global core.quotepath false
```
