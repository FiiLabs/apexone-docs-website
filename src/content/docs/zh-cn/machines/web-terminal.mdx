title: 网页终端
description: "SSH 配置坏了时，从浏览器进入机器。"
---
import { Aside } from '@astrojs/starlight/components';

网页终端是**SSH 用不了时的出路**（私钥丢了、公钥还没换好）。在机器页的「网页终端」里打开，然后点「打开终端」。

<Aside type="caution" title="要说清楚的代价">
	网页终端的会话内容**技术上会经过我们的服务器**（不录制、不落盘）。所以它**默认关闭**，由你按机器打开、用完可以随时关掉；
	每次开关和每一次会话都记进「操作记录」，你可以核对我们有没有用过。想完全不经过我们，就用你自己的终端 SSH。
</Aside>

机器在待机中时，打开终端会唤醒它（约 10 秒）。
