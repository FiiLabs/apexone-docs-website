---
title: 重装系统
description: "换一块全新的系统盘，你的数据原样保留。"
---
import { Aside } from '@astrojs/starlight/components';

系统被改坏了、想回到干净状态时，在机器页点「重装系统」，或在机器里运行 `hangar reimage`（需要输入机器名确认）。

| 会保留 | 会丢失 |
|---|---|
| `/home`（在加密盘上，包括 AI 工具的凭据） | 系统盘上的一切：`apt` 装的包、`/etc` 的改动、`/opt`、`/usr/local` |
| `/root`、`/tmp`、`/var/log` | 内存里的东西（机器会重启） |
| SSH 主机密钥（不会出现「主机密钥变了」的警告） | |

预装的 AI 工具会重新安装（约 2 分钟）。想让重装后自动恢复你的环境，把安装步骤写进 `~/.hangar/setup.sh`。

<Aside type="note">
	重装不收费，这次开机在账单里记作「不计费」。数据盘全程不解密、不读取，只换系统盘。
</Aside>
