---
title: 开放端口
description: "机器没有独立公网 IP，用「服务器 IP : 端口」对外提供服务。"
---
import { Aside } from '@astrojs/starlight/components';

机器页 → **外部访问**：填机器里的端口和协议（TCP / UDP），系统在 **20000–29999** 里分配一个外部端口。别人访问 `服务器IP:外部端口` 就会转到你机器里的那个端口。

- 我们只转发字节，看不到 TCP 会话的内容。
- 目前不支持绑定自己的域名和自动 HTTPS。
- 你的多台机器之间网络不互通（故意的：一台被攻破不会连到另一台）。
- 出网的 25 端口是封的，发不了邮件；465 / 587 正常。

<Aside type="caution" title="UDP">
	UDP 端口不能触发唤醒。开着 UDP 映射的机器不会自动待机——否则它睡着后你的 UDP 服务就静默不可用了。
</Aside>
