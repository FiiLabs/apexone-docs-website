**新机器默认关闭自动待机**（一直开着，每月最多收上限价）。可以在开通时勾选，或之后在机器页里打开。

## 什么时候会待机

打开后，连续 20 分钟（可改）**同时**满足这三条才会待机：

- 没有任何已建立的连接（进出都算，比如 SSH 会话、Claude Code 和模型的连接）；
- CPU 基本空闲；
- 几乎没有网络流量。

任何一条不满足就不待机；读不到数据时也按「在用」处理。

## 待机时发生了什么

机器的内存整块写进加密盘，物理内存还给服务器，加密钥匙随后从内存里移除。**待机期间只收基础费，不收开机小时费。**

## 怎么唤醒

直接 SSH 或访问已映射的端口：连接一到，我们在后台把机器开起来再转发，大约多等 10 秒。进程、打开的文件、内存里的数据都在。

也可以在机器里立刻待机：`hangar hibernate`。

<Aside type="caution">
	- 待机期间 **cron 等定时任务不会运行**，有定时任务的机器别开自动待机。
	- 开着 **UDP** 端口映射的机器不会自动待机（UDP 不能触发唤醒）。
	- 余额不足时机器会被切到待机，和这个开关无关，见 [价格与计费](/zh-cn/billing/pricing/)。
</Aside>
