## 常见报错

### 401 Unauthorized

- API Key 无效、已过期或已被吊销。
- Base URL 填错了——必须是 `https://api.apex1.us`（OpenAI SDK 风格的客户端用 `https://api.apex1.us/v1`）。
- 鉴权文件（`auth.json` / `settings.json`）不是合法 JSON。

### 连不上

- 确认你的网络能访问 `https://api.apex1.us`。
- 检查公司代理或防火墙是否拦截了出站 HTTPS。

### 找不到模型

- 对照概览页的[支持的模型](/zh-cn/#supported-models)列表核对模型名。
- 确认该模型包含在你当前的套餐里。

## 常见疑问

### 我的数据会被用来训练吗？

不会。用户的请求与响应**绝不**用于模型训练。想自己验证「包括我们在内的任何中间方都读不到」这件事？见[隐私证明](/zh-cn/verification/privacy-proof/)。

### 不同工具需要各自的 Key 吗？

不需要。一个 ApexOne API Key 可以同时用于 Claude Code、Codex CLI、OpenCode、Cursor、Cline 以及直接调用 API。你也可以在控制台创建多个 Key，按项目分开统计用量。

### 怎么查看用量和费用？

[ApexOne 控制台](https://apex1.us)实时展示所有请求、token 用量、费用与缓存统计——每一次调用都附带一张可验证的推理回执。

### 上游厂商挂了会怎样？

ApexOne 的自动故障切换会在后台把流量改道，你的应用继续收到响应，不需要改任何代码。每一次切换都会记录在你的回执里。

### 怎么获得企业级接入？

企业方案、定制 SLA 与批量定价请联系 **support@apex1.us**。

## 共享你的订阅

### 用订阅承接了我请求的那个人，能读到我的 prompt 吗？

不能——共享订阅这条路由上不能。共享者贡献的是**额度**，不是服务器：请求离开我们的 TEE 之后直达上游厂商，全程不经过共享者的任何设备。他们只能看到自己的额度被消耗了。

确实有一条路由会让 prompt 到达第三方基础设施——由共享者自己提供 API 端点的中转接入——它在[你的请求是怎么被服务的](/zh-cn/#how-your-requests-are-served)里被明确列出。站点运营方可以把这条路由整个关掉。

### 共享订阅能赚多少？

我们承诺的是**分成比例**——平台向用户收取金额的 50%——以及零手续费的链上结算。我们不承诺具体金额：那取决于真实需求量，而平台仍在早期，需求还在积累。计算方式见[共享你的订阅](/zh-cn/earn/share-subscription/)。

### 为什么我的收益还不能提现？

收益要经过 **72 小时冻结期**才能提现——这段时间覆盖的是消费者的银行卡付款仍可能被拒付的窗口。见[收益与提现](/zh-cn/earn/earnings-and-withdrawals/)。

### 账号接上了，但一直没有收益。

先看它的状态。处在**观察期**的账号还没有开始接单——它要连续通过若干次探测、并且熬满最短观察时长之后才会进入共享池。而一个**已经在接单**却没有收益的账号，只是没有请求被路由过来。
