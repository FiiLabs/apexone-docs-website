## 系统级权限规则

预装的 Claude Code 带一份系统级配置（`/etc/claude-code/managed-settings.json`，root 所有）。它的优先级最高，Claude 自己改不掉。默认：

- 不读 `~/.ssh`、`~/.aws`、`~/.kube`、`.env`、`*.pem` 这类常见的密钥路径；
- 不执行 `sudo`、`su`、改防火墙、`nsenter` 这类命令。

<Aside type="caution" title="诚实的边界">
	权限规则是**便利性护栏，不是安全边界**：Claude 用 Bash 换个写法仍可能读到这些文件。真正承重的是下面的 `~/private`。
</Aside>

## ~/private：对 Claude 完全不可见

Claude Code 运行在一个隔离的命名空间里，`~/private` 在它眼里是一个空的只读目录——换什么写法都读不到。不想让 Claude 碰的东西（私钥、云凭据、生产配置）放这里。

```bash
hangar private     # 看它挡得住什么、挡不住什么
```

## 查看与关闭

```bash
hangar security          # 当前加固状态
sudo hangar security off # 关掉加固（需要 sudo——Claude 没有 sudo）
sudo hangar security on  # 重新打开
```
