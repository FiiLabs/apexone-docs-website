**ApexOne 是一台装好 Claude Code 的云端开发机。** 开机就有官方 Claude Code，还能在开通时顺带买好 Claude Pro 账号、由我们替你登录。它是一台有 root 的完整虚拟机：Claude 能装依赖、跑 Docker、跑测试；你合上笔记本，它在云上继续干活。

<CardGrid>
	<Card title="开机就能用 Claude Code" icon="laptop">
		预装官方 Claude Code（还有 Codex）、Node、Docker、git 和编译工具链，开机约 2 分钟装好。
	</Card>
	<Card title="账号可以一起买好" icon="star">
		开通时选 Claude Pro，我们用平台账号替你登录；已有账号的选「自己登录」，不加价。
	</Card>
	<Card title="合上电脑它接着跑" icon="rocket">
		机器在云上，SSH 断开也不影响；配合 tmux 跑几个小时的长任务。
	</Card>
	<Card title="Claude Code 保持最新" icon="approve-check">
		预装版本由平台统一升级，先经过兼容性检查；你也可以自己装更新的版本。
	</Card>
</CardGrid>

<Aside type="tip" title="价格一句话">
	一直开着，每月最多收「上限价」，和同配置云主机同价；开启自动待机后，闲着只收基础费。
	Claude 账号另按 30 天一期收。当前价格以 [价格页](https://apex1.us/pricing) 为准。
</Aside>
