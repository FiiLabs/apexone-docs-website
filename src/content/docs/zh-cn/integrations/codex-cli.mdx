把 [Codex CLI](https://developers.openai.com/codex/quickstart) 配置成使用 ApexOne 作为 API 提供方。

## 前置条件

安装 Codex CLI 之前，先确认以下组件已就位：

- **Node.js 22 或更高版本**

<LinkCard
	title="安装前置"
	description="为你的操作系统装好 Node.js。"
	href="/zh-cn/getting-started/install/"
/>

## 安装 Codex CLI

全局安装：

```sh
npm install -g @openai/codex
```

验证安装：

```sh
codex --version
```

能打印出版本号，说明安装成功。

## 配置 Codex CLI

Codex 的配置存放在用户主目录下的 `.codex` 目录里。

### 配置文件位置

<Tabs syncKey="os">
	<TabItem label="Windows">

	```
	%USERPROFILE%\.codex
	```

	目录不存在就先创建：

	```
	mkdir %USERPROFILE%\.codex
	```

	</TabItem>
	<TabItem label="macOS">

	```
	~/.codex
	```

	目录不存在就先创建：

	```sh
	mkdir -p ~/.codex
	```

	</TabItem>
	<TabItem label="Linux">

	```
	~/.codex
	```

	目录不存在就先创建：

	```sh
	mkdir -p ~/.codex
	```

	</TabItem>
</Tabs>

### 创建 `auth.json`

```json title="~/.codex/auth.json"
{
  "OPENAI_API_KEY": "YOUR_API_KEY"
}
```

<Aside type="caution" title="字段名不要改">
	**不要**把 `OPENAI_API_KEY` 这个字段名改掉——它是 Codex CLI 认的配置键名。
	只需要把 `YOUR_API_KEY` 换成你的 ApexOne API Key。
</Aside>

### 创建 `config.toml`

```toml title="~/.codex/config.toml"
model_provider = "OpenAI"
model = "gpt-6"
review_model = "gpt-6"
model_reasoning_effort = "high"

[model_providers.OpenAI]
name = "OpenAI"
base_url = "https://api.apex1.us"
wire_api = "responses"
requires_openai_auth = true
```

<Aside type="tip">
	更多可配项见官方的 [Codex 配置参考](https://developers.openai.com/codex/config-basic)。
</Aside>

## 验证配置

<Steps>

1. 在任意项目目录下启动 Codex CLI：

   ```sh
   codex
   ```

2. 首次启动时，Codex 可能会询问是否允许它在当前仓库里工作。按你的使用习惯选择。

3. 发一条 prompt 测试连接。收到响应就说明配置生效了。

</Steps>

## 排障

<Aside type="caution" title="401 Unauthorized">
	通常是 API Key 无效、`base_url` 填错，或者 `auth.json` 不是合法 JSON。两个文件都核对一下：

	- `~/.codex/auth.json` 的 `OPENAI_API_KEY` 里是一个有效的 ApexOne Key。
	- `~/.codex/config.toml` 里 `base_url = "https://api.apex1.us"`。
</Aside>

## 升级 Codex CLI

```sh
npm install -g @openai/codex@latest
```
