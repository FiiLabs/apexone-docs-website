你多半在按月付一笔固定的 Claude 或 ChatGPT 订阅费，却只用掉其中一小部分。ApexOne 让你把剩下的部分用起来：接入你的账号，当别人的请求由你的闲置额度完成时，你从他付的钱里拿一份。

<Aside type="caution" title="我们承诺什么，不承诺什么">
	我们承诺的是**分成比例**（目前 50%）以及结算方式。我们**不**承诺你能赚多少：
	那取决于平台上的真实需求量，而平台仍在早期，需求还在积累。早期收益可能相当有限。
	你用下面的公式算出来的任何数字都是估算，不是承诺。
</Aside>

## 它是怎么运作的

<Steps>

1. **接入你的订阅。** 通过 OAuth 授权一个账号，或者提供一个兼容的 API 端点。两种方式都可以随时下线或解绑。

2. **你的闲置额度被使用。** 平台把请求路由到你的账号，只动用你自己没用掉的那部分额度。

3. **你拿走一部分收入。** 平台向用户收取的每一笔费用，你拿其中的 50%。

</Steps>

## 完整流程：从零到开始赚钱

下面是全过程，一步一点。操作只要几分钟；之后的等待比操作本身久。

<Steps>

1. **登录并打开共享控制台。**

   打开 [ApexOne 控制台](https://apex1.us)登录。在左侧导航里找到 **共享赚钱** 分区，点击 **共享订阅**。

   如果你看不到这个分区，说明本站点没有启用共享功能——这不是你这边能解决的，请联系运营方。

2. **阅读并同意供给者协议。**

   这是一道一次性的门：不同意就无法接入任何账号。关于数据处理的那部分值得真的读一遍——
   你承担的义务会因为下一步选哪种接入方式而不同。

   勾选后点击**同意并继续**。

3. **选择平台，然后接入订阅。**

   先选你要共享的是 **Claude** 还是 **ChatGPT** 订阅，然后接入。Claude 有两种方式
   （见[下面的对比](#two-ways-to-connect)——拿不准就选 OAuth）；ChatGPT 只支持 OAuth。

   **OAuth——推荐（Claude 与 ChatGPT 都适用）。** 点击**连接我的订阅**。新标签页会打开厂商的授权页面。
   同意授权，复制它给你的那段码，粘回表单，点击**完成接入**。链接约 15 分钟内有效，过期重来一次即可。

   **API 中转（仅 Claude）。** 填入一个 Anthropic 兼容的 base URL（`https://…`，不要带路径后缀——
   平台会自己拼上 `/v1/messages`）以及对应的 API Key。提交时平台会发一次极小的真实请求来确认端点有响应，
   所以 Key 填错会当场失败，而不是默默地不工作。

4. **等观察期跑完。**

   你的账号现在显示**观察中**。平台会定期探测它；连续通过若干次探测、并且最短观察时长也满足之后，
   它才会进入共享池并开始接单。

   **这段时间你没有收益。这是正常的，不是故障。**

5. **绑定收款地址——等待期间就可以做。**

   在提现区域，粘贴你在结算链上的钱包地址。从钱包里复制，不要手打。

6. **看它开始工作。**

   账号开始接单之后，**累计收益**就会变动，每一笔请求也会出现在收益流水里。
   收益先进入冻结窗口，之后转为可提现。

</Steps>

<Aside type="tip" title="观察期过了却什么都没发生">
	一个已经在池子里却没有收益的账号，只是还没有流量被路由过来。那是需求侧的现实——
	你的配置没有任何需要修的地方。先看账号状态：**观察中**与**接单中**是两回事。
</Aside>

## 两种接入方式

<CardGrid>
	<Card title="OAuth（推荐）" icon="approve-check-circle">
		授权你的 Claude 或 ChatGPT 账号，把码粘回来即可。请求**经我们的 TEE 网关**到达厂商——
		全程不经过你的任何设备，所以你不会接触到任何用户数据。
	</Card>
	<Card title="API 中转（仅 Claude）" icon="setting">
		提供一个 Anthropic 兼容的 `/v1/messages` 端点及其 Key。请求会被转发到**你的**服务器，
		这意味着用户的 prompt 会流经你运维的基础设施——见下方的义务说明。站点运营方可以关闭这条路由。
	</Card>
</CardGrid>

<Aside type="note" title="如果你接的是中转端点">
	中转的请求会把别人的 prompt 内容带到你控制的服务器上。你有义务妥善处理这些数据；
	供给者协议里写明了这一条。如果你不愿意承担，请使用 OAuth 方式——它不会让任何用户内容经过你的机器。
</Aside>

## 观察期

新接入的账号**不会**立刻开始接单。它会进入观察期，平台定期探测并记录结果。
只有在连续通过若干次探测**并且**最短观察时长也已满足之后，账号才会进入共享池。

这道门对双方都是保护：你不会希望自己对平台的第一印象是一个配置错误的端点持续报错，
而消费者也不该被路由到一个根本服务不了他们的账号上。

<Aside type="tip" title="看探测结果，不要看时钟">
	探测失败时，控制台会显示原因。最常见的原因是授权过期——重新接入即可解决。
	一次失败会把「连续成功次数」清零，所以一个时好时坏的端点会一直留在观察期，
	而不会进入池子去坑用户。
</Aside>

## 分成怎么算

```
你的收益 = 用户为这次用量实际支付的金额 × 分成比例（50%）
```

基数是**平台向用户收取的金额**，不是厂商的官方牌价。这个区别很重要，因为 ApexOne 是按官方牌价的一个折扣向消费者计费的，而这个折扣按平台而定——Claude 用量按牌价的 14% 计费，ChatGPT 用量按 20%：

| 每 $1 官方牌价的用量 | Claude | ChatGPT |
| --- | --- | --- |
| 用户被收取 | $0.14 | $0.20 |
| **你拿到（50%）** | **$0.07** | **$0.10** |
| 平台留存（50%） | $0.07 | $0.10 |

分成比例在**两个平台上都是 50%**；不同的是消费者那一侧的计费倍率，而它决定了你分成的基数。

<Aside type="note" title="为什么分成的基数是实收金额，不是牌价">
	说成「牌价的 50%」会是一个大得多的数字，而且是假的。下游的一切——你的流水、你的提现、
	我们的对账——都以实际收到的金额计价，所以分成也只能以它为基数。
</Aside>

## 你能看到与看不到什么

你能看到：你的哪个账号服务了多少请求、各自赚了多少，以及这些数字背后的每一条流水。

你**看不到**：消费者是谁，或者他问了什么。在 OAuth 路由上，内容压根不会到达你这里；
在流水里，消费者身份在数据离开 API 之前就已经在服务端被剥掉了。

## 把账号收回来

两个不同的动作，区别很重要：

- **下线**——停止接收新请求，进入排空窗口。已经在传输中的请求会正常跑完，窗口打开期间你可以取消。
  凭证仍然由平台保管。
- **解绑**——停止接收新请求，**并且**永久删除我们持有的授权凭证。此操作不可撤销，
  重新接入意味着要再走一遍观察期。

已经产生的收益不受这两个动作影响，仍可正常提取。

<Aside type="note" title="解绑不会撤销上游的授权">
	删除我们这边的凭证副本，能让 ApexOne 无法再使用该账号。如果你还想在厂商一侧撤销授权，
	请到你的 Claude 或 ChatGPT（OpenAI）账号设置里移除它。
</Aside>
