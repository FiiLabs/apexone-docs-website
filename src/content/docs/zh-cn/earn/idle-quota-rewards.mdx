## 天数是怎么算的

这一节值得仔细看，因为奖励**只**取决于它。

<Steps>

1. **接入你的账号。** 一次 OAuth 授权即可，不需要 API Key，也不需要密码。逐步操作见
   [共享你的订阅](/zh-cn/earn/share-subscription/)。

2. **通过接入探测。** 我们会发一次简短的探测，确认账号能承接真实流量，通常一小时内完成。
   **账号进入共享池之前，天数不开始计算。**

3. **保持在线。** 账号每保持连接且可接单一天，计数加一。

4. **掉线时计数暂停，不会清零。** 把账号接回来，天数从停下的地方继续。
   但**解绑之后再重新接入会变成一个新账号，天数从零开始**。

</Steps>

<Aside type="note" title="不需要有流量也能达标">
	计数看的是「可用」而不是「用过」。一个已连接、可调度的账号，即便某天恰好没有请求被路由过来，
	当天照样计数。做不到的是「接入一个不能服务的账号」——凭证过期、或者订阅已经没有额度，
	账号会被移出共享池，计数也随之停止。
</Aside>

## 怎么拿到钱

奖励进入的是与分成收益同一个贡献者钱包，规则也相同：

- 余额经过 **72 小时冻结期**后可提现。
- 提现以 **BNB Chain 上的 USDT** 发放，通常几分钟内到账。
- **零提现手续费——gas 由平台承担。**

提现前需要先绑定收款地址，这一步见[收益与提现](/zh-cn/earn/earnings-and-withdrawals/)。

## 名额是怎么用完的

每一档都有固定名额，按账号接入的先后分配——上线更早的账号排在更晚接入的前面。
某一档名额发完后，那一档停止发放，其余档位不受影响。

活动没有固定的结束日期。奖励发完即结束，或者出现下方「须知」中的情况时提前结束。

## 须知

- 你始终掌握自己的账号。随时可以在面板上解绑；一小段排空窗口会让在途请求正常跑完。
- 我们承诺的是分成比例、以及本页列出的奖励金额与门槛。我们**不**承诺任何具体的分成收益数字
  ——那取决于你的账号实际承接了多少流量。
- 把订阅额度共享给第三方使用是否符合你与上游厂商之间的服务条款，需要你自行判断。
- 如果上游厂商的政策发生变化，我们可能暂停或结束本活动。
