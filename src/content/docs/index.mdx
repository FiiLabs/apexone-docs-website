**ApexOne is a cloud dev machine with Claude Code installed.** Official Claude Code is there at boot, and you can add a Claude Pro account at creation that we sign in for you. It is a full virtual machine with root: Claude can install dependencies, run Docker and run your tests — close your laptop and it keeps working in the cloud.

<CardGrid>
	<Card title="Claude Code, ready at boot" icon="laptop">
		Official Claude Code (and Codex), Node, Docker, git and a build toolchain, installed about two minutes after boot.
	</Card>
	<Card title="Get the account with it" icon="star">
		Pick Claude Pro at creation and we sign the machine in with a platform account. Already have one? Choose <em>Use my own</em> at no extra charge.
	</Card>
	<Card title="Close your laptop, it keeps going" icon="rocket">
		The machine lives in the cloud, so dropping SSH doesn't matter. Pair it with tmux for tasks that run for hours.
	</Card>
	<Card title="Claude Code stays up to date" icon="approve-check">
		The platform updates the pre-installed version for every machine after a compatibility check; you can also install a newer version yourself.
	</Card>
</CardGrid>

<Aside type="tip" title="Pricing in one line">
	Kept running, a machine never costs more per month than its cap — about the same as a comparable cloud server. Turn on auto-suspend and idle time costs only the base fee.
	A Claude account is billed separately every 30 days. See the [pricing page](https://apex1.us/pricing) for current prices.
</Aside>
