---
title: Commands on the machine
description: "Quick reference for the hangar command."
---
Run `hangar` on the machine for help. Common commands:

| Command | What it does |
|---|---|
| `hangar status` | Machine status: spec, auto-suspend, balance, disks |
| `hangar auth` | Wizard to sign in to Claude / Codex |
| `hangar auth status` | Credential status |
| `hangar keep-awake 4h` | Pause auto-suspend for a while (`90m`, `off`; up to 24 hours) |
| `hangar hibernate` | Suspend now |
| `hangar security` | Claude guardrail status; `sudo hangar security off/on` to toggle |
| `hangar private` | What `~/private` is and what it protects against |
| `hangar reimage` | Reimage the system disk (data kept) |
| `hangar claude-update` | Pre-installed Claude Code version and auto-update; `sudo hangar claude-update off/on/now` |
| `hangar diag` | Build a diagnostic report — shown to you first, sent only if you confirm |
